키움증권 계좌 이체 방법(원화, 외화 모두 알려드림)

작성일 2022년 7월 15일
이 글의 금융 제도·금리·한도·수치는 2022년 7월 작성 시점 기준입니다. 현재 기준과 다를 수 있으니 실제 결정 전에는 해당 기관의 최신 안내를 확인해 주세요.

키움증권은 주식 투자를 시작할 때 가장 쉽게 접할 수 있는 증권사입니다. 수시로 진행하는 계좌 개설 이벤트를 통해 수수료나 환율 우대를 많이 받을 수 있기 때문이죠.

그런데 UI가 다소 복잡해서 조작이 까다롭다는 단점이 있습니다. 처음 시작하는 분들을 위해 키움증권 계좌 이체 방법을 알려드리겠습니다.

1. 키움증권 계좌 이체 방법 – 원화

다른 은행에서 키움증권 계좌로 입금하는 방법은 굳이 설명드릴 필요 없겠죠? 은행 어플 등으로 키움증권 계좌로 온라인 송금을 하면 되니까요.

참고로 연계은행 계좌에서 키움증권 계좌로 이체하는 경우라면, 영웅문에서도 처리가 가능합니다.

  • 영웅문S(MTS) : 업무 → 입출금 → 입금
  • 영웅문(HTS) : [0801] 연계은행 입출금

키움증권 → 타은행 계좌 출금 방법

키움 증권계좌에서 은행계좌로 이체하는 방법도 간단합니다. 다만 연계은행 계좌가 아니라면, ‘지정계좌 등록’을 반드시 해야 합니다.

  • 영웅문S(MTS) : 메뉴 → 업무 → 입출금/출고 → 출금 → 지정계좌 선택
  • 영웅문(HTS) : 온라인 업무 → 인터넷 뱅킹 → 즉시이체 출금

지정계좌 등록을 하려면 OTP 카드가 필요하고요. 연계은행 계좌로 이체(출금)하는 거라면, 「[0801]연계은행 입출금(MTS : 업무 → 입출금 → 출금)」에서 간단하게 처리할 수 있습니다.

※ 계좌이체(출금) 가능 시간 : 00:30 ~ 23:30 (평일은 16:50~17:00 입금불가)

이체 수수료는 500원이 발생하는데, 우수 고객이거나 키움증권 계좌(혹은 연계은행 계좌)로 출금하는 경우에는 면제됩니다.

영웅문S 글로벌 이용할 경우

해외주식 투자를 위해 ‘영웅문S 글로벌’ MTS를 이용하는 분들도 있을 텐데요. 이 경우에 MTS에서 외화 뿐만 아니라 원화도 자유롭게 입출금할 수 있습니다.

「메뉴 → 업무 → 입출금 → 출금」에서 계좌이체가 가능하고요. 마찬가지로 이체할 계좌를 지정계좌로 등록한 다음 출금하면 됩니다.

2. 키움증권 계좌 이체 – 외화

사실 원화 계좌이체는 크게 어렵지 않습니다. 많은 분들이 헷갈리는 게 외화 이체 부분인데요. 더군다나 키움증권은 대부분 해외주식 투자 때문에 이용하시잖아요.

‘영웅문 글로벌 S’ MTS 기준으로 외화 이체(입출금)하는 방법을 설명드려볼게요.

타은행 → 키움증권 외화 송금

사업을 하시거나, 기타 이유로 계좌에 달러가 있는 분들은 직접 외화를 증권계좌에 송금하고 싶을 수 있습니다.

환전 수수료를 굳이 내지 않고 직접 해외주식에 투자할 수 있기 때문이죠.

또한 일반적으로 은행보다 증권사 환율 우대가 크기 때문에, 증권사 계좌에 이체한 다음 환전하는 식으로 활용할 수도 있습니다.

저도 소소하지만 약간의 애드센스 수익이 발생하는데, 이런 식으로 환전을 하고 있어요.

아무튼 키움증권 계좌로 외화를 이체하려면 「업무 → 메뉴 → 입출금 → 외화가상계좌 등록/해지」에서 가상계좌를 만들어야 합니다.

아래와 같이 국민은행에 가상 외화계좌가 만들어지는데요. 은행 뱅킹 어플에서 이 계좌로 (타사)외화 이체를 하면 됩니다.

이체할 때 실시간으로 내 계좌가 맞는지 확인할 수 있고요. 보통 이체 수수료가 몇 천원 정도 발생하니 참고하세요.

3. 키움증권 → 타은행 외화 송금

반대로 키움 증권계좌에서 다른 은행계좌로 외화 이체하는 것도 가능합니다.

※ 메뉴 → 입출금 → 외화이체(타사)

다른 은행이나 증권사 환율 우대가 더 클 때는, 이렇게 외화를 이체한 다음에 우대율이 높은 곳에서 환전하면 되겠죠?

다만 마찬가지로 이체할 때 몇 천원 정도의 수수료가 발생할 수 있으니, 보유한 외화가 소액인 경우에는 수수료가 더 비쌀 수 있다는 점 유의하세요.

지금까지 키움증권 계좌 이체 방법을 상황별로 정리해봤습니다. 이밖에 더 궁금한 점이 있다면 키움증권 이용가이드를 참고해보셔도 좋을 것 같네요.
